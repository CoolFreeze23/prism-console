# Ore UI integration

Source: the Prism Launcher theme `Ore UI - Dark Emerald` (installed under `PrismLauncher/themes`).

Original theme by Nursultan Akim. See UPSTREAM-LICENSE.md and the individual
SVG `.license` sidecars for original copyright and MIT license terms.
SVG files are copied unchanged. `../oreui.css` adapts the theme palette and
Qt border-image styling to CSS, with console-sized targets, white focus
outlines, responsive spacing, and reduced-motion support from style.css.

No proprietary Minecraft font is bundled. The other five installed variants
and native desktop-dialog theme selection are not modified by this port.
